# Kickstarter Crowdfunding Analysis Project

## 📌 Project Overview 
Analyzed crowdfunding campaign data using Excel, SQL, Power BI, and Tableau. Cleaned, transformed, and validated datasets, performed exploratory analysis to identify funding trends and success factors, and built interactive dashboards and visualizations to deliver actionable insights and track campaign performance.

## 🔧 Tools & Technologies  
- Excel  
- Power BI  
- Tableau  
- MySQL  
- Data Cleaning & Visualization

## 📊 Key Insights  
- Analyzed campaign categories, funding goals, pledged amounts, and timelines.  
- Used **MySQL** queries to extract and preprocess relevant data.  
- Built interactive dashboards to compare successful vs failed campaigns.  
- Provided actionable insights into campaign performance trends.

## 🚀 How to Use  
1. Download the files from Google Drive.  
2. Run the SQL queries on MySQL to explore structured data.  
3. Open dashboards in Excel / Power BI / Tableau.  
4. Interact with visualizations to explore insights.
